LogLover est une application de bureau développée en Python permettant d'importer, de stocker et d'analyser des fichiers de logs (.log). Elle importe les fichiers logs fournies par l'utilisateurs et permet de les trier et d'affiche des graphiques.

## Technologies utilisées
Python avec Pyqt6 pour le GUI et Squlite3 pour la bdd.

## Tester
Pour tester l'application prenez la version disponible dans l'onglet release du github. C'est un executable portable sans dépendance. Des données de test sont disponible sur le github dans le fichier log_test.LOG.
